# Employee Attrition Analysis

## Project Overview

This project analyzes employee attrition using the IBM HR Analytics Employee Attrition dataset. The objective is to identify the factors that influence employee turnover and build a machine learning model to predict attrition.

## Dataset

* Dataset: IBM HR Analytics Employee Attrition Dataset
* Total Records: 1470
* Features: 35

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn
* Google Colab

## Exploratory Data Analysis (EDA)

The following analyses were performed:

* Attrition Distribution
* Department-wise Attrition
* Age vs Attrition
* Monthly Income vs Attrition
* Job Satisfaction vs Attrition
* Work-Life Balance vs Attrition

## Key Insights

* Employees aged 25–35 show higher attrition.
* Lower-income employees are more likely to leave the organization.
* Low job satisfaction is strongly associated with attrition.
* Better work-life balance improves employee retention.
* Research & Development and Sales departments show relatively higher attrition.

## Machine Learning Model

**Model Used:** Logistic Regression

## Model Performance

**Accuracy:** 90.13%

## Conclusion

The analysis identified key factors influencing employee attrition and developed a predictive model with good accuracy. The findings can help organizations improve employee retention strategies through better compensation, employee engagement, and work-life balance initiatives.
